# AI Customer Support Agent — Case Studies

Three case study solutions for designing AI agents for high-volume customer support.

## Case Studies

| # | Topic | Key Tech |
|---|-------|----------|
| 1 | [E-Commerce Support Agent](case-study-1-ecommerce/) | LangChain + RAG (FAISS) |
| 2 | [Banking Support Agent](case-study-2-banking/) | Secure validation + GitHub Copilot |
| 3 | [Multi-Agent Enterprise Support](case-study-3-google-adk-langchain/) | Google ADK + LangChain |

## Setup

```bash
pip install -r requirements.txt
```

Set your Gemini API key:
```bash
export GOOGLE_API_KEY="your-gemini-key-here"
```

## Running

Open any `agent.ipynb` notebook in Jupyter and run all cells:
```bash
jupyter notebook
```

Each notebook is self-contained with mock data, agent logic, and sample conversations.
